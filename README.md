# 🏦 Sistema Bancário em Python

Este é um projeto de simulação de terminal bancário desenvolvido em Python para praticar estruturas de dados como **Dicionários** e **Listas**.

## 🚀 Funcionalidades
* Autenticação simples de utilizador.
* Consulta de saldo contabilístico.
* Sistema de levantamentos com verificação de saldo.
* Histórico dinâmico de operações utilizando listas.
* Interface limpa através do terminal.

## 🛠️ Tecnologias Utilizadas
* Python 3
* Biblioteca interna `os` (para manipulação do terminal)
* Biblioteca interna `time` (para simulação de transações)

## 🗂️ Como Executar
1. Instale o Python no seu computador.
2. Clone este repositório.
3. Execute o ficheiro principal no terminal:
   ```bash
   python main.py
